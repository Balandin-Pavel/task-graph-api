# TaskGraph API

Учебный проект на Java 17: вычисления образуют граф зависимостей.
Результат запрашивается по идентификатору и кэшируется после первого
вычисления. Для работы с графом есть локальный HTTP API.

Реализованы неизменяемые узлы, типы операций, проверка зависимостей и
арифметического переполнения. Поддерживаются целые константы и сложение.

## Запуск и тесты

```bash
./run.sh test
./run.sh server
```

Требуется JDK 17+. Зависимостей и сетевых запросов для сборки нет.

## API

```bash
curl -X POST http://127.0.0.1:8081/tasks -d 'id=a&type=constant&value=21'
curl -X POST http://127.0.0.1:8081/tasks -d 'id=b&type=sum&left=a&right=a'
curl http://127.0.0.1:8081/tasks/b
```

Данные хранятся в памяти; сервер привязан к localhost. Это демонстрационный
проект без аутентификации и постоянного хранилища.
